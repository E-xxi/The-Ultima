# THE Ultima — 지구 문자 (디자인 대기 중)

지구에 남은 공동체(조지아 스바네티 지역 화자)가 직접 쓴 문자입니다. 기록문자([`../record-script/`](../record-script/))와 달리 **뜻과 문법**을 담습니다.

이 폴더에 지구 문자 디자인을 넣습니다. 구조는 `record-script/`와 같게 맞춥니다(`earth-script-guide.png`, `data/`, `src/`, `assets/svg/`, `preview/`).

## 지금 정해진 것 (세계관·스테이지 문서 기준)

- **문자 표기 관습:** 표지(구분 기호), 기호 방향, 반전 문장, 묶음 칸, 세로줄, 존칭 선행, 이름 테두리.
- **문법 구분 (언어 쪽):** 들은 말 / 본 말(증거성), 청자 포함 / 배제 '우리'.
- **석판:** 부조, 기록문자 줄, 지구 문자 줄이 함께 새겨져 있습니다.

## 게임의 임시 데이터

지금 게임은 `game/data/language.json`의 `speaker`(형태소마다 7×7 픽셀 기호)를 임시로 씁니다. 이 폴더의 디자인이 나오면 교체합니다.
