THE Ultima · 범용 기록문자 견본

v0.1.0 · 임시 그래픽

1. 자음 기본 획 = 조음 위치

이누크티투트 음절문자의 p·t·g·k·q 계열 모양을 참고. 안쪽(목 쪽)일수록 고리가 늘어난다.

2. 회전 = 후두 특성 (장애음만)

0° 기본 · 90° 유성 · 180° 유기 · 270° 방출. 공명음은 회전하지 않는다.

3. 조음 방법 = 획 끝 표시

파열 무표 · 비음 끝 점 · 마찰 평행 획 · 접근 끝 말림. 유음(l, r) 등은 미정.

4. 2차 조음 = 기본 획 축소 부착

해당 위치의 기본 획을 40%로 줄여 오른쪽 위에 붙인다 (회전하지 않음).

5. 모음 = 고리 + 라틴 글자

모든 모음은 고리에서 시작한다. 자음에는 고리가 없다. 비음은 위 점, 장음은 윗줄.

6. 음절 블록 = 자음 수만큼 길어지고, 한 음절은 이어 쓴다

자음→자음은 바닥선에서, 자음→모음은 고리로, 모음→받침은 획 끝에서 연결. 음절 사이는 끊는다. 받침은 60% 작은 꼴.

7. 단어

모든 글자 모양은 임시 그래픽이다. 규칙(획 체계·회전·표시 방식·블록 배치)만 확정 상태이며, 전체 음소 목록과 최종 그래픽은 미확정.
