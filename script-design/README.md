# 문자 디자인

게임에 나오는 두 문자의 디자인을 모아 둔 곳입니다. 둘은 성격이 다르므로 폴더를 나눕니다.

| 폴더 | 이름 | 무엇인가 | 담는 정보 | 게임에서 쓰는 곳 |
| --- | --- | --- | --- | --- |
| [`record-script/`](record-script/) | **기록문자** (범용 기록문자) | 이주 이전에 여러 언어의 발음을 적으려고 만든 인공 표기 체계. 언어가 아님 | **소리만** (자음·모음·보조 부호, 음절 블록) | 0단계 학습, 석판의 소리 줄, 지구에서 잊힌 구별 복원 |
| [`earth-script/`](earth-script/) | **지구 문자** | 지구에 남은 공동체(스바네티 지역 화자)가 직접 쓴 문자 | **뜻과 문법** (어휘 기호, 표지, 방향, 이름 테두리 등) | 1~5단계 해독 퍼즐 |

> 기록문자를 읽으면 **소리**를 추정할 수 있고, 지구 문자를 해독하면 **뜻**을 알 수 있습니다. "읽을 수 있다 ≠ 이해한다"는 이 구분에서 나옵니다.

## 폴더 규칙

- 두 폴더는 같은 구조를 씁니다.

  ```
  <문자>/
    README.md               규칙 요약, 미정 사항
    <문자>-guide.png        견본 한 장 (예: record-script-guide.png)
    data/                   글자 규칙·모양 데이터
    src/                    렌더러
    tools/                  에셋 빌드
    assets/svg/             개별 글자 SVG
    preview/                견본 시트
  ```

- 견본이 새 버전으로 바뀌면 이미지 파일 이름은 그대로 두고 README 맨 위의 버전을 고칩니다.
- 디자인 폴더는 **원본**입니다. 게임은 `game/data/`의 데이터를 읽습니다. 연결 상태는 아래와 같습니다.

## 게임 데이터와의 연결 (2026-11-18 현재)

| 문자 | 디자인 원본 | 게임 데이터 | 상태 |
| --- | --- | --- | --- |
| 기록문자 | `0-1_game_script/` (렌더러·`graphemes.json`·`phonemes.sample.json`, 0단계 연습 명세와 데이터) | `game/src/scriptRenderer.js`, `game/data/graphemes.json`, `phonemes.json`, `stage0.json` | 원본을 **그대로 복사**. `npm test`가 같은지 확인 |
| 기록문자 (이전 판) | `record-script/` | — | `0-1_game_script/`보다 예전 판. 견본 이미지만 참고용 |
| 지구 문자 | (아직 없음) | `game/data/language.json`의 `speaker` (7×7 픽셀 임시 기호) | 디자인이 나오면 교체 |
