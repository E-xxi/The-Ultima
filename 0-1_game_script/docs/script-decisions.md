# THE Ultima — 범용 기록문자 디자인 결정 (임시안 v0.1)

> 개발 지침(기록문자 및 특수 발화 시스템)의 2장을 그래픽 규칙으로 구체화한 기록이다. 글자 모양은 모두 **임시 그래픽**이며, 전체 음소 목록은 아직 확정하지 않았다. 아래는 '규칙'만 확정한다.

## 1. 모음
- 모든 모음은 **작은 고리에서 획이 시작**하고, 이어서 라틴 글자 모양을 따라간다 (a, e, i, o, u, ʌ…).
- 자음에는 고리가 절대 없다 → 고리 유무가 모음/자음 1차 구분.
- /ʌ/는 입술 자음(꺾쇠 ∧)과 헷갈리지 않도록 **가로획 추가**.
- 비음화(ã): 모음 위 **점**.
- 장음(aː): 모음 위 **가로줄(마크론)**.
- 비음화 장모음(ãː): 가로줄 위에 점.

## 2. 자음 — 이누크티투트 음절문자 참고
### 조음 위치 = 기본 획
| 위치 | 기본 획 | 참고 |
|---|---|---|
| 입술 | 꺾쇠 ∧ | 이누크티투트 p 계열 |
| 잇몸 | 아치 ∩ | t 계열 |
| 경구개 | 갈고리 | g 계열 |
| 연구개 | 고리 달린 기둥 (P형) | k 계열 |
| 구개수 | 고리 두 개 (B형) | q 계열 — 안쪽일수록 고리 추가 |

### 후두 특성 = 회전 (장애음에만 적용)
- 0° 기본 · 90° 유성 · 180° 유기 · 270° 방출 (예: k, g, kʰ, kʼ)
- 카르트벨리어족(스바네티어)의 유성·유기·방출 3계열과 대응.
- 공명음(비음·접근음 등)은 회전하지 않고 0° 고정.
- 지침 2장 "보조 부호로 구별"을 이 계열 구분에 한해 **회전으로 대체**함. 유사 발음이 기본 형태를 공유한다는 원칙은 유지.

### 조음 방법 표시
- 파열: 무표
- 비음: 획 끝 **점** (모음 비음화의 점과 같은 의미로 통일)
- 마찰: 획 끝에 **짧은 평행 획**
- 접근(w, j): 획 끝 **말림**
- 유음(l, r) 등 나머지: 미정

### 2차 조음 (보조 부호)
- 해당 조음 위치의 기본 획을 **작게 축소해 오른쪽 위에 덧붙임**.
- 순음화 ʷ = 작은 꺾쇠, 구개음화 ʲ = 작은 갈고리.

## 3. 음절 블록
- **블록 길이는 자음 수만큼 늘어난다** (고정 정사각형 아님).
- **한 음절 안에서는 획을 이어 쓴다.**
  - 자음→자음: 바닥선에서 연결
  - 자음→모음: 연결선이 모음의 고리로 들어감
  - 모음→받침: 모음 획 끝에서 바로 연결
  - 음절 사이는 끊김 → 플레이어가 소리를 몰라도 음절 경계부터 찾을 수 있음
- 받침은 **작은 꼴**(60%)로 쓴다 (이누크티투트 끝소리 문자 참고), 위치는 오른쪽 아래, 바닥선 정렬.
- 연결점 선택은 바닥선 우선: 나가는 점 = argmax(x + 1.5y), 들어오는 점 = argmax(−x + 1.5y).

## 4. 데이터 모델 반영 포인트
- `Grapheme`: 기본 획 path + 연결 앵커. 그래픽(SVG/폰트)은 교체 가능하게 분리.
- `PhoneticFeature` → 그래픽 규칙 매핑: 조음 위치→기본 획, 후두 특성→회전 각도, 조음 방법→끝 표시, 2차 조음→축소 부착.
- `Diacritic`: 비음 점, 장음 마크론, 2차 조음 축소형.
- `SyllableBlock`: 구조(CV/CVC/CCV/CCCV…)별 슬롯 위치·크기, 자음 수에 따라 가변 폭, 앵커 연결 로직.

## 5. 샘플
- /kʼãː/ (지침 예시): 270° 회전 연구개 + 고리 a + 마크론 + 점
- 지원 /dʑi.wʌn/: 90° 회전 갈고리 + i / 말림 꺾쇠 + 가로획 ʌ + 작은 아치·점 받침

## 6. 미정
- 유음(l, r), 성문음 등 나머지 조음 방법 표시
- 전체 음소 목록과 최종 글자 그래픽
- 특수 발화 기호(휘파람) 그래픽 — 지침 4장의 임시 기호 유지
