# 스테이지 0 · 출발 전 연습 — 게임 디자인 명세

참조 구현: `stage0/index.html` (`node tools/build-stage0.mjs`로 생성, 단일 HTML)
데이터: `data/stage0.json` · 문자 규칙: `data/graphemes.json` · 음소: `data/phonemes.sample.json`

## 1. 목표
플레이어는 한 소리만 다른 단어 쌍(감자/강자/감사…)을 비교해, **어떤 소리가 음절 블록의 어느 자리에, 어떤 모양·크기로 적히는지** 스스로 발견한다. 시작 시 아는 글자는 /a/ 하나, 끝나면 8글자(ㅏ ㅜ ㄱ ㄴ ㅁ ㅇ ㅅ ㅈ)와 규칙 5개를 얻는다.

## 2. 흐름
`intro → compare ×5 → read ×5 → write ×3 → done`
상단에 단계 표시(비교·읽기·쓰기, 문제 수만큼 점), 오른쪽에 해독 노트(좁은 화면에서는 아래).

## 3. 화면별 명세

### 3.1 intro — 교과서 한 과
- 쪽 머리말: "범용 기록문자 입문" / "LHS 고고언어학 연구실 교재"
- "제0과" · 제목 "소리를 적는 글자" · 리드 한 줄 (서기 4100년, 출발 전)
- 상자 "이 과에서 배울 것" 3항목: 자음/모음 구별 · 글자의 자리와 크기 · 비교로 새 글자 찾기
- 1절 범용 기록문자란 + '주의' 상자: 읽을 수 있음 ≠ 언어를 이해함 (개발 지침 3장)
- 2절 음절 블록 + 그림 0-1: '감자'를 크게 렌더하고 1음절·2음절 괄호, '끊김', 첫소리(자음·고리 없음)/모음(고리에서 시작)/받침(작은 꼴) 이름표. **이름표 위치는 렌더러가 배치한 실제 좌표에서 계산**(글자 모양이 바뀌어도 따라가야 함)
- 3절 비교로 읽기 + 표 0-1 알려진 글자(글자·한글·발음·종류)
- 버튼 "제0과 연습 시작" · 옆에 "비교 5 · 읽기 5 · 쓰기 3"
- 본문은 교과서체("~다")

### 3.2 compare — 달라진 글자 찾기 (5라운드)
- **안내 문구 없음.** 화면에는 단어 카드 두 장(한글 단어 + 기록문자)만.
- 글자(파트) 단위 클릭. 차이는 `(음절 순번, 자리)` 키로 두 단어의 음소를 비교해 자동 계산.
- 정답 클릭: **한쪽만 눌러도 두 단어의 달라진 글자가 모두 선택**(강조 박스) + 각 글자 아래 **한글 이름표**(ㅁ, ㅇ…). 정답 문구는 띄우지 않는다.
- 공개 카드: 새로 알게 된 글자(기록문자 + 한글 + /IPA/ + 힌트) + **한 줄 설명 "N째 음절의 {첫소리|모음|받침}입니다."** (자동 생성). 버튼 "다음 비교" / 마지막은 "읽기 연습으로".
- 해독 노트에 글자 추가(강조 애니메이션) + 규칙 1개 추가.
- 오답 클릭: 해당 글자 빨간 강조 + 카드 흔들림(0.6초), 문구 "N음절의 {자리}는 두 단어에서 같은 글자예요. 다른 자리를 찾아보세요."

| # | 쌍 | 공개 | 노트에 추가될 규칙 |
|---|---|---|---|
| 1 | 감자/강자 | ㅁ /m/, ㅇ /ŋ/ | 받침은 오른쪽 아래에 작게. 끝의 점은 비음. |
| 2 | 감자/감사 | ㅈ /dʑ/, ㅅ /s/ | 평행 획은 마찰음. 회전한 글자는 울림소리(유성). |
| 3 | 감사/간사 | ㄴ /n/ | 기본 획은 소리 나는 위치(입술·잇몸·목 안쪽). |
| 4 | 감사/감수 | ㅜ /u/ | 모음은 모두 고리에서 시작한다. |
| 5 | 감자/남자 | ㄱ /k/, ㄴ /n/ | 같은 자음이 첫소리에선 크게, 받침에선 작게. |

### 3.3 read — 기록 읽기 (5문제)
- 기록문자 단어 하나(한글 없음) + 비슷한 단어 4지선다.
- 오답: 버튼 빨간색·비활성, **고른 단어와 정답의 차이 자리를 기록 위에 빨갛게 표시**, 문구 "{고른 단어}(이)라면 표시한 자리(N음절 {자리})가 달라야 해요." 재시도 가능.
- 정답: 버튼 초록, 다음 버튼.
- 문제: 강사·상자·간수·상수·남산 (보기는 stage0.json)

### 3.4 write — 기록 쓰기 (3문제)
- 목표 한글 단어 제시. 음절마다 첫소리·모음·받침 3칸.
- 칸 선택 → 아래 팔레트에서 글자 선택. **팔레트는 모양만, 한글/IPA 표기 없음**(노트를 보고 기억해서 써야 함). 첫소리·받침 칸은 자음만, 모음 칸은 모음만, 받침 칸에는 '없음' 추가.
- 글자를 넣으면 다음 빈 칸으로 자동 이동. 미리 보기에 실시간 조립.
- 확인: 틀린 칸 빨간 표시 / 전부 맞으면 "완벽해요." 후 다음.
- 문제: 강수·상자·남산

### 3.5 done
"출발 준비 완료." + 글자 수·규칙 수 + 13개 단어 기록 모음 + "처음부터 다시"(노트·규칙 초기화).

## 4. 표기상 결정
- 기록문자는 실제 발음을 적는다: 울림소리 사이의 ㅈ → /dʑ/ (90° 회전 갈고리). 받침 ㅇ → /ŋ/ (연구개 + 비음 점).
- 연습 단어는 한국어지만 이야기에서 주인공 모국어로 단정하지 않는다("익숙한 단어").

## 5. 상태 모델 (참조 구현)
```
phase: intro|compare|read|write|done, i: 현재 문제 번호, solved: bool
known: Set<phonemeId>   ← DeciphermentProgress (확정 규칙)
rules: string[]         ← 발견한 규칙 문장
comp: [{onset0, nucleus, coda0}] (write 단계 입력)  ← TranscriptionHypothesis 성격
```
플레이어 입력(가설)과 정답 데이터(stage0.json)는 분리되어 있다 (개발 지침 5장 유의 사항 5).
